# Error codes proposal

0x0000 OK; 0x0001 BUSY; 0x0002 UNSUPPORTED; 0x0003 INVALID_STATE; 0x0004 BAD_FRAME; 0x0005 BAD_CRC; 0x0006 REQUEST_ID_CONFLICT; 0x0007 SESSION_MISMATCH; 0x0008 PREPARE_WINDOW_EXPIRED; 0x0009 DEVICE_MISMATCH; 0x000A VERSION_REJECTED; 0x000B IMAGE_TOO_LARGE; 0x000C PARTITION_TOO_SMALL; 0x000D OFFSET_ERROR; 0x000E SEQUENCE_ERROR; 0x000F WRITE_FAILED; 0x0010 SIZE_MISMATCH; 0x0011 HASH_MISMATCH; 0x0012 IMAGE_INVALID; 0x0013 TLS_FAILED; 0x0014 HTTP_FAILED; 0x0015 WIFI_NOT_CONNECTED; 0x0016 DOWNLOAD_INTERRUPTED; 0x0017 TIMEOUT; 0x0018 ABORTED; 0x0019 INTERNAL_ERROR.

Keep App-local BLE errors separate from device error codes. Log timestamp, MAC, UUID, request/session ID, command HEX, parsed result and error origin.
